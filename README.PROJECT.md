# Digitalization Company Website Adaptation

This overlay converts the existing Cruip Open Next.js template into a structured Codex/GSD/Graphify project for a German digitalization company serving small businesses.

It intentionally does not contain or overwrite application source code, package manifests, lockfiles, or framework configuration. The existing template remains the technical foundation.

## Target offer

- Document management and paper-document digitalization
- AI consulting and workflow automation
- Data analysis
- Dashboards and reporting

## Primary website purpose

A clean corporate homepage and digital business card that explains the offer and converts visitors into consultation requests.

## Important files

- `AGENTS.md`: Codex repository instructions
- `TASK.md`: ordered execution phases
- `START_CODEX.md`: first Codex command
- `docs/`: product, content, design, architecture, testing, assets, and compliance guidance
- `.codex/agents/`: specialized subagents
- `.agents/skills/`: reusable project workflows
- `planning/`: GSD bootstrap notes
- `graphify/`: graph usage guidance

Keep the original Cruip README and license information in the repository.
